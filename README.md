# Project ôn tập Boya để upload Netlify

Thư mục này là một website tĩnh. Bạn có thể upload nguyên thư mục `BOYA_REVIEW_NETLIFY` lên Netlify.

## Cách upload nhanh

1. Mở Netlify.
2. Chọn **Add new site**.
3. Chọn **Deploy manually**.
4. Kéo thả cả thư mục `BOYA_REVIEW_NETLIFY` vào Netlify.
5. Sau khi deploy xong, mở link Netlify trên điện thoại hoặc iPad.

## File chính

- `index.html`: trang chọn 5 bài ôn tập.
- `reviews/ON_TAP_BOYA_BAI_01_06.html`: ôn tập Bài 01 đến 06.
- `reviews/ON_TAP_BOYA_BAI_07_12.html`: ôn tập Bài 07 đến 12.
- `reviews/ON_TAP_BOYA_BAI_13_18.html`: ôn tập Bài 13 đến 18.
- `reviews/ON_TAP_BOYA_BAI_19_24.html`: ôn tập Bài 19 đến 24.
- `reviews/ON_TAP_BOYA_BAI_25_30.html`: ôn tập Bài 25 đến 30.

Mỗi file HTML tự chấm điểm trong trình duyệt, không cần backend.
