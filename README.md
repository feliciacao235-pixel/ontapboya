# Boya Chinese HTML Course

Website tĩnh gồm 30 bài giảng HTML và 6 bài ôn tập.

## Cấu trúc

- `index.html`: trang chủ.
- `lessons/`: 30 bài giảng.
- `reviews/`: 6 bài ôn tập, mỗi bài sau 5 bài học.

## Đưa lên GitHub Pages

1. Tạo repository GitHub mới.
2. Upload toàn bộ nội dung thư mục này.
3. Vào Settings > Pages.
4. Chọn GitHub Actions.
5. Chờ workflow deploy xong.

Học viên mở link GitHub Pages trên điện thoại hoặc iPad.
